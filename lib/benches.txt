# The benchmark set, one name per line. The scripts turn each into the regexp
# ^Name(/|$), so a name has to be the full function name and matches its literal
# sub-benchmarks. A name that matches nothing at the ref under test is ignored,
# which is what lets one list serve every tag; a set where nothing at all matches
# is an error.
#
# Rules for what goes here: flat or a handful of literal subs, deterministic,
# a few seconds at default benchtime, no grid over sizes or counts (the retired
# MerkleCommit grid produced 45 series that all moved together and were most of
# a session's run time), and nothing that opens sockets or sleeps. ROADMAP.md
# lists what was considered and left out, and why.
#
# Every name here ran at master (8cd5eb5f6, 2026-09-15) in one session of 217s
# at -count 1 on an M2 Pro, 55 series. Names marked "since" do not exist at the
# older stable tags and are skipped there.

# --- noise sentinel (patches/add-noise-sentinel.sh, not go-algorand code) ----
# Fixed work that does not depend on the ref. If these move, the machine did.
BenchmarkNoiseSentinelHash
BenchmarkNoiseSentinelLoop

# --- transaction verification (data/transactions/verify) --------------------
BenchmarkTxn                    # one signed txn through verify, the ed25519 path
BenchmarkPaysetGroups           # a block's groups through the verify execpool
BenchmarkTinyMan                # a real mainnet swap group: lsig eval, group check (3 subs)

# --- txn handler and pool (data, data/pools) ---------------------------------
BenchmarkTxHandlerProcessing    # processDecoded and verify.TxnGroup (2 subs)
BenchmarkTxHandlerDecoderMsgp   # wire decode of a txn group
BenchmarkAppRateLimiter_TxgroupToKeys   # app rate limiter key derivation, seeded
BenchmarkStatusCachePut         # pending-txn status cache, the /v2/transactions/pending path
BenchmarkStatusCacheCheckHit
BenchmarkStatusCacheCheckMiss

# --- AVM (data/transactions/logic) ------------------------------------------

BenchmarkCheckx5                # CheckSignature over five real programs
BenchmarkAddx64                 # interpreter dispatch, add x64 at two stack depths (2 subs)
BenchmarkNopPassx1              # smallest program that passes
BenchmarkVerify                 # crypto opcodes: ed25519verify_bare, ecdsa k1/r1, falcon_verify, vrf_verify, plus pop and add (7 subs)

# --- basics, committee (data/basics, data/committee) -------------------------
BenchmarkAddressFormatting      # address checksum, every REST round trip
BenchmarkUnmarshalChecksumAddress
BenchmarkSortition              # VRF verify plus sortition, per agreement vote, seeded

BenchmarkOnlineAccountsCacheRead320     # agreement-round online lookups
BenchmarkBlockEvaluatorRAMNoCrypto      # 50k-txn block through Eval, ~14s setup, ~0.7s/op
BenchmarkPay                    # full payment blocks under ConsensusFuture; since v5, fails on proposer at older tags
BenchmarkAppInt1                # full app-call blocks, same harness

# --- crypto --------------------------------------------------------------------

BenchmarkOneTimeSigBatchVerification    # the agreement vote signature, three backends (3 subs)
BenchmarkVrfVerify              # VRF verify, libsodium; keygen per b.N in untimed setup
BenchmarkAdd                    # crypto/merkletrie, the catchpoint trie
